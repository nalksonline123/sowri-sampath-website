# Sowri Sampath & Co. — Landing Page

Static single-page website for GitHub Pages.

## Files
- index.html — page
- style.css — responsive styling
- favicon.svg — browser icon
- assets/brand-preview.jpg — social/share preview image

## Deployment
Upload these files to a public GitHub repository and enable GitHub Pages from the `main` branch/root.

Do not change BigRock DNS until the GitHub Pages site has been tested.
